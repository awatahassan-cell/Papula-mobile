# پەپوولە (Papoole) - Kurdish (Sorani) Kids Mobile App (React Native)

ئەپڵیکەیشنی فێرکاری مۆبایل بۆ منداڵانی کورد (سۆرانی) تەمەن ٣ بۆ ٨ ساڵ، دروستکراو بە تەکنەلۆژیای **React Native** و **Expo**.

---

## 📱 تایبەتمەندییە سەرەکییەکان (Features)

1. **دروستکردنی پرۆفایلی منداڵ (Onboarding)**: هەڵبژاردنی ناو، ئاژەڵی دڵخواز (🦋, 🦊, 🐻, 🦁, 🐰, 🐬) و گرووپی تەمەن.
2. **پەڕەی سەرەکی (Home)**: ٣ کارتی سەرەکی بە دەستلێدان (ئەلفوبێ، چیرۆکەکان، نووسین)، ژمێریاری ڕۆژانی بەردەوامی (Streak 🔥)، کۆی ئەستێرەکان (⭐)، و دەستپێکی خێرای مەشقی ڕۆژانە.
3. **تۆڕی ئەلفوبێ (٣٣ پیت)**: گشت ٣٣ پیتەکەی کوردی سۆرانی، جیاکردنەوەی پیتە قورسەکان (وەک ڕ و ڵ)، و فلتەرکردنی پیتە فێربووەکان.
4. **تایبەتمەندی پیت (Letter Detail)**:
   - پیتی گەورە لەگەڵ بێژەکردنی دەنگ.
   - ٤ شێوازەکەی پیت (تەنیا، دەستپێک، ناوەڕاست، کۆتایی).
   - ٣ وشەی نموونەیی لەگەڵ وێنە و بێژەکردن و خەزنکردن.
   - تۆمارکەری دەنگ (Voice Recorder) بە `expo-audio` بۆ بەراوردکردنی دەنگی منداڵەکە.
5. **یاری دەنگ و ناسینەوە (Match Game)**: ٥ قۆناغی پڕ لە کەیف و سەفا، گوێگرتن لە دەنگ و هەڵبژاردنی پیتی دروست.
6. **ڕاهێنانی نووسین بە پەنجە (Writing & Tracing Canvas)**:
   - کێشانی هێڵەکان بە پەنجە لە ڕێگەی `react-native-svg` و `PanResponder`.
   - ٤ هێڵی ستانداردی دەفتەری کوردی (سەروو، ناوەڕاست، بنەڕەت، خواروو).
   - هێڵی ڕێبەر و پیشاندانی جووڵەی پیتەکە بە جووڵە (Animated Demo).
   - هەڵبژاردنی بۆیەی تەباشیری فرەڕەنگ، گەڕانەوە، و سڕینەوە.
   - ئەلگۆریتمی هەڵسەنگاندنی نووسین و پێدانی ١ تا ٣ ئەستێرە.
7. **خوێنەری چیرۆکی کارلێککار (Story Reader)**:
   - دوو دۆخی خوێندنەوە: *بۆم بخوێنەوە* و *خۆم دەخوێنمەوە*.
   - ڕووناکبوونەوەی وشە بە وشە بە شێوازی کاراوکێ بەپێی کاتی ڕاستەقینە (`wordTimings`).
   - پەنجەنان لە هەر وشەیەک بۆ بیستنی و خەزنکردنی لە "وشەکانم".
   - تاقیکردنەوەی تێگەیشتن لە چیرۆکەکە لە کۆتاییدا.
8. **ئەرکەکانی ڕۆژانە (Daily Missions)**: ئەرکی نووسین، خوێندنەوە و یاری بۆ بەدەستهێنانی خەڵاتی ئەستێرە.
9. **ئەلبوومی ستیکەر و میدالیاکان (Stickers & Badges)**: کردنەوەی ستیکەری جوان و نیشانەکان بە زیادبوونی ئەستێرەکان.
10. **داشبۆردی دایک و باوک (Parent Dashboard & Gate)**:
    - پارێزراو بە پرسیاری بیرکاری (Math Gate) بە کوردی.
    - کۆنتڕۆڵی کاتی بەکارهێنان (١٥ تا ٩٠ خولەک).
    - قفڵی کاتی خەوتن (Bedtime Lock).
    - ئەنجامدانی تاقیکردنەوەکانی کۆد لەناو ئەپەکەدا (Unit Test Runner).

## 🚀 چۆنیەتی کارپێکردن (How to Run)

بڕۆ ناو فۆڵدەری پڕۆژەکە لەسەر دیسکتۆپ:
```bash
cd PapulaMobile
```

### کارپێکردن:
```bash
npx expo start
```

- **لەسەر مۆبایلی ڕاستەقینە**: ئەپی **Expo Go** لە Play Store (ئەندرۆید) یان App Store (ئایفۆن) دابەزێنە و کۆدی QRەکە بە کامێراکەت سکان بکە.
- **لەسەر ئەندرۆید ئێمیولەیتەر**: پیتی `a` دابگرە.
- **لەسەر براوسەری وێب**: پیتی `w` دابگرە.

### دروستکردنی فایلی APK بۆ ئەندرۆید:
```bash
npx eas build -p android --profile preview
```
یان بە شێوەی ناوخۆیی (Local Build):
```bash
npx expo run:android
```
